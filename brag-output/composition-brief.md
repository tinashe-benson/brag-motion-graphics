# Hyperframes Composition Brief: Argo

## Objective
Create a 60-second launch showreel for Argo, the AI Agent for scaling founders.

## Output
- Composition directory: `brag-output/composition/`
- Rendered video: `brag-output/brag.mp4`
- Format: landscape — 1920x1080, 30fps
- Duration: 60s (user override of brag's 15–25s window)

## Creative Direction
- Tone preset: cinematic, with polished restraint
- Creative direction: premium AI-product showreel
- Angle: noise → one agent → the foundation → the real dashboard → just ask in Slack, approve, done → governed by design
- Hook: nine real app tiles pinging in a navy void; "Nine tools. One founder. Zero context."
- Outro: "Research. Write. Operate. Follow up." → Argo lockup + hireargo.ai
- Avoid: generic SaaS language, abstract filler, invented metrics, real personal data (screenshot email replaced)
